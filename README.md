# MySkate Coach

Plans your next figure skating session from a [MySkate](https://github.com/iiSurf/MySkate) backup. Claude reads your log and decides what to practice and for how long; plain code checks every part of the plan before you see it.

Being built. The plan is in [LOG.md](LOG.md).
